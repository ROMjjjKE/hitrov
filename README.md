# Кровельные работы, Барановичи

Статический сайт для ИП Хитров К. А. Один лендинг и страница политики данных.
Без сборки, без зависимостей, без внешних библиотек.

## Что внутри

- `index.html` — лендинг: услуги, материалы, этапы, объекты, о работе с 2011 года, FAQ, форма.
- `politika.html` — политика обработки персональных данных.
- `assets/css/style.css` — все стили, токены цвета и типографики в `:root`.
- `assets/js/main.js` — меню, плавный скролл, подсветка навигации, валидация формы.
- `assets/img/` — фотографии.

## Заголовки

Каждый заголовок отвечает на конкретную боль клиента, а не описывает красоту:
«Крыша течёт или пора менять», «Говорим цену до начала», «Что проверяем, чтобы
не текло через год». При правках держите этот принцип: заголовок = ответ на
возражение, а не слоган.

## Публикация

Репозиторий: https://github.com/ROMjjjKE/hitrov
Сайт: https://romjjjke.github.io/hitrov/

Обновление: закоммитить изменения в ветку `main`, GitHub Pages пересоберётся сам.

Свой домен: Settings → Pages → Custom domain, затем заменить
`https://romjjjke.github.io/hitrov/` на новый адрес в `index.html` (canonical,
`og:url`, `og:image`, микроразметка), `politika.html`, `sitemap.xml` и `robots.txt`.

## Форма заявки

Сейчас кнопка показывает готовое сообщение и два пути: звонок и WhatsApp со
вписанным текстом заявки. Чтобы заявки приходили на почту или в CRM, впишите
адрес приёмника в `assets/js/main.js`:

```js
var CONFIG = {
  formEndpoint: 'https://formspree.io/f/XXXXXXX'
};
```

Форма начнёт отправлять JSON `{ name, phone, work, place, message }` методом POST.

## Что заменить перед передачей клиенту

1. Фотографии в `assets/img/` — сейчас демонстрационные. Заменить на реальные
   объекты, имена файлов и размеры сохранить.
2. В `politika.html` указать УНП, адрес и e-mail для обращений.
3. Проверить у клиента формулировки про зимние работы, гарантийные сроки и
   порядок оплаты: на сайте описан только общепринятый порядок работ.
4. Телефон, домен и часы приёма звонков правятся поиском по файлам.

## Проверки

- Анти-слоп-линтер (Nutlope/hallmark): 0 FAIL, 0 REFLEX, 0 WARN.
- Адаптив от 320 px, горизонтального скролла нет.
- Контраст текста не ниже 4.5:1.
- Без JS контент виден: анимации только в `prefers-reduced-motion: no-preference`.
